## ⚡ How to Install & Run in Termux

Copy and run the following commands **one by one** in your Termux terminal:

### Steps
```bash
pkg update && pkg upgrade -y
```

```bash
pkg install git -y

```
```bash
git clone https://github.com/Pasidu2010/Madushanka-lag-fix-tool.git
```
```bash
cd Madushanka-lag-fix-tool

```
```bash
chmod +x Madushanka

```
```bash
./Madushanka

```
